# v0.9.24

## Для кого этот релиз

Стабильный выпуск для пользователей, которым нужна актуальная версия Mihomo с сохранением интеграции FlClash и Android VPN.

## Что изменилось для пользователя

- Сетевое ядро обновлено с Mihomo v1.19.30 до v1.19.31.
- Добавлены EasyTier outbound, `stack: mips` для TUN и `identity-secret` для ZeroTier.
- Получены исправления Hysteria v1/v2, VLESS, WireGuard, AmneziaWG v3, OpenVPN, DNS через Tailscale и обработки сетевых соединений.
- Поверх новой стабильной версии сохранён адаптационный слой FlClash для TUN, слушателей, прокси, провайдеров и геобаз.

## Что это даёт на практике

- Исправлены утечки ресурсов и ошибки закрытия соединений в нескольких транспортных протоколах.
- Улучшена устойчивость TUN и снижено потребление памяти в сетевом стеке.
- Новые возможности ядра доступны без изменения существующей Android-интеграции клиента.
