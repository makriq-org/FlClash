# v0.9.21-pre1

## Для кого этот релиз

Предварительный релиз для пользователей Android, который добавляет короткую автоматическую диагностику после успешного применения профиля.

## Что изменилось для пользователя

- После применения профиля приложение отправляет технический отчёт о текущем Android-состоянии.
- Отчёт не содержит секреты, ссылку профиля, журналы соединений и полный список установленных приложений.
- Если сети нет, приложение продолжает работать без ошибок и действий пользователя.

## Технические заметки

- Единственная точка отправки: успешный `profile_applied` после применения профиля к ядру.
- Отправка идёт в `https://diag.makriq.com/v1/report`.
- Локально хранится UUID установки и подпись последней попытки отправки.
- Для того же состояния действует ограничение один отчёт в сутки; при изменении версии приложения, профиля, режима маршрутизации или списка исключённых пакетов отчёт отправляется сразу.
