# v0.9.21

## Для кого этот релиз

Стабильный Android-релиз с короткой автоматической диагностикой после запуска или применения профиля.

## Что изменилось для пользователя

- После запуска или применения профиля приложение отправляет технический отчёт о текущем Android-состоянии.
- Отчёт не содержит секреты, ссылку профиля, журналы соединений и полный список установленных приложений.
- Если первая отправка не дошла из-за сети, приложение повторит её при следующем запуске или применении профиля.
- Успешно отправленные одинаковые отчёты ограничены одним разом в сутки.

## Технические заметки

- Точка отправки: `https://diag.makriq.com/v1/report`.
- Состояние последней диагностической отправки сохраняется только после успешного ответа Worker.
- В отчёт входят только короткие поля состояния: версия Android, устройство, версия приложения, имя профиля, время обновления профиля, режим маршрутизации, доступ к списку приложений и явно исключённые пакеты.
