# v0.9.25

## Для кого этот релиз

Стабильный выпуск для пользователей FlClash, которым нужна актуальная версия сетевого ядра.

## Что изменилось для пользователя

- Mihomo обновлён с v1.19.31 до v1.19.33 с сохранением интеграции FlClash.
- Добавлена настройка режима DNS для TUN и обновлён сетевой стек TUN.
- Исправлены закрытие встроенного Shadowsocks, обработка DNS через HTTPS и сохранение состояния fake IP при обновлении конфигурации.
- Включены исправление безопасности TLS и улучшения OpenVPN, WireGuard, EasyTier и балансировки соединений.

## Что это даёт на практике

- Более устойчивую работу DNS и сетевых соединений при обновлении конфигурации.
- Исправления безопасности и совместимости в протоколах, используемых приложением.
