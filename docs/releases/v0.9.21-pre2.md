# v0.9.21-pre2

## Для кого этот релиз

Предварительный релиз для пользователей Android, которым нужна диагностика сразу после запуска VPN, а не только после обновления профиля.

## Что изменилось для пользователя

- Если первая отправка диагностики не дошла из-за сети, приложение повторит её при следующем запуске или применении профиля.
- Успешно отправленные одинаковые отчёты по-прежнему ограничены одним разом в сутки.

## Технические заметки

- Состояние последней диагностической отправки сохраняется только после успешного ответа Worker.
- Это убирает ложную суточную задержку после сетевой ошибки на старте.
