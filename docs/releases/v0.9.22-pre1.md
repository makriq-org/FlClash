# v0.9.22-pre1

## Для кого этот релиз

Предрелиз для обкатки нового подъёма сетевого ядра перед следующим стабильным выпуском.

## Что изменилось для пользователя

- Клиент переведён на более свежую линию mihomo с набором исправлений устойчивости и защитных доработок.
- Улучшена совместимость с новыми типами подключений и конфигурациями, которые раньше могли работать непредсказуемо.
- Переход на новое ядро согласован с клиентской обвязкой, чтобы не ломались выбор прокси и обновление геобаз.

## Технические заметки

- Подмодуль core/Clash.Meta поднят с c27f82f до 80362fc.
- Обвязка core переведена на новые вызовы AllProxies и UpdateGeoData без path-вариантов.
- Обновлены зависимости Go для сборки новой ревизии ядра в действиях.
